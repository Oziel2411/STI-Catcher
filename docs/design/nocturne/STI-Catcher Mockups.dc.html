2Nocturne · varios links, varios archivos y elección de pantalla

Supuestos. Cada link o archivo es su propio trabajo en la cola, con su formato de salida. En Descargar, elegir WebM/MOV/MKV/WAV/GIF encadena la descarga con una conversión (el server ya sabe hacer ambas). La variante A de cada par es densa (tabla, barra superior); la B es más cómoda (tarjetas o maestro‑detalle, barra lateral).

Pantalla o ventana. El navegador no deja que una página liste las ventanas abiertas: la lista real siempre la muestra el diálogo del navegador. Lo que sí se puede es elegir antes el tipo (pantalla, ventana o pestaña) para que ese diálogo abra en esa solapa, y mostrar una vista previa de lo elegido antes de empezar a grabar, con «Cambiar».
